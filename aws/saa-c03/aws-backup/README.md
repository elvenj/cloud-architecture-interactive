# AWS Backup — arquitetura interativa SAA-C03

Abra `index.html` a partir do repositório com a estrutura preservada (ou use GitHub Pages).

### Inclui
- 7 etapas de arquitetura, 5 vistas e painel técnico por componente;
- 12 questões contextualizadas, com opções em inglês e justificativa de cada distrator;
- fundos originais por categoria: Gestão e Governança, Armazenamento e Segurança/KMS;
- galeria de todas as 16 imagens originais e links à documentação AWS;
- cópia da arquitetura em PNG para a área de transferência do Chrome e colagem no Ulysses.

Os 16 PNG originais ficam em `../../assets/category-backgrounds/`. Não mova ou renomeie esses arquivos sem também atualizar as referências.

**Nota:** a Clipboard API exige contexto permitido pelo navegador e acesso às imagens de mesmo domínio; em GitHub Pages isso é atendido por HTTPS. Algumas instalações locais ou restrições de navegador podem impedir a cópia; falhas são exibidas no botão.

Os conectores entre planos, cofres e recursos são associações conceituais, não caminhos físicos de transferência de dados.
