# Interactive Cloud Architecture

Biblioteca de arquiteturas interativas de AWS,
Google Cloud e Azure.

## Estrutura
- index.html: catálogo principal.
- aws/saa-c03/gateway-endpoints/index.html:
  primeira arquitetura interativa completa.
- gcp/ e azure/: conteúdos futuros.

## Adicionar arquiteturas
1. Crie uma pasta para o novo tema.
2. Copie seu HTML como index.html nessa pasta.
3. Execute ./update-catalog.sh.
4. Faça commit e push para publicar.
